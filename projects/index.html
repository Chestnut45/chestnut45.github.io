Theseus

An action roguelike PC game built entirely in C++ by my wonderful classmates and I for our capstone project.

Phi

An unfinished micro-engine prototype for game development on Linux and Windows using OpenGL 4.6. I developed this primarily to use for assignments in the computer graphics programming course at UPEI, and it should not be used for production.

Cityscape

A procedurally generated infinite cityscape with a deferred renderer, shadow mapping, a dynamic day-night cycle, and snow accumulation. Built with an early version of the Phi micro-engine for the final assignment of the computer graphics programming course at UPEI.
